# Changelog

## 0.1.0 — unreleased

First version for Minecraft 26.3 (Fabric). Browse community schematics in game and download them
for Litematica.

- A key (unbound by default) opens the vault.
- Search by title, author or tag; filter by category; sort by newest or size.
- Details of each design: authors, size, block count, Minecraft version, license and source.
- 3D preview of each design with the game's own blocks and textures: turn, move and zoom it.
- Block editor in the full-screen preview: list of blocks with counts, replace or remove any of them
  and download the edited copy (old MCEdit files are saved as `.litematic`).
- Layer slider in the full-screen preview: see the design up to any layer, floor by floor.
- Block replacements follow the layers shown: change a block on some floors only, in the 3D and in
  the saved file; several changes of one block can coexist and each has its own undo.
- Download any file into `schematics/Schematic Vault/`, checked before it is saved.
- With Litematica installed: "Load in Litematica" and "Place here" (hologram at your position),
  also for edited designs.
- With Litematica installed: a "Community schematics" button in its main menu opens the vault.
- With Litematica installed: its schematic browser shows the selected file turning in 3D, with
  "Enlarge and edit" for layers, materials and the block editor on your own files.
- With Litematica installed: a "Generate thumbnails" button in its schematic browser gives the files
  of the open folder a picture in their rows, only when you ask, with progress and Cancel.
- Works offline with the last catalog downloaded.
- Settings screen (gear button in the vault, or Mod Menu): catalog address, download folder, 3D
  preview limit and the vault's key.
- 17 languages.
